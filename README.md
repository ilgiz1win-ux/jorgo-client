# Jorgo — электровелосипед дүкөнү (мобилдик колдонмо)

Электровелосипеддерди, запчасттарды сатуу жана оңдоо кызматы үчүн онлайн-дүкөн.
React Native + Expo (SDK 58) + Expo Router менен жазылган — Android, iOS жана веб үчүн бир код.

## Мүмкүнчүлүктөр

- **Башкы бет** — категориялар, популярдуу товарлар, оңдоо кызматына баннер
- **Каталог** — издөө, категория боюнча чыпкалоо, баа боюнча иреттөө
- **Товар барагы** — сүрөттөмө, мүнөздөмөлөр, арзандатуу, сатыкта бар/жок, WhatsApp аркылуу суроо
- **Себет** — санын өзгөртүү, өчүрүү, акысыз жеткирүүгө чейинки сумма (телефондо сакталат)
- **Буйрутма берүү** — аты, телефон, дүкөндөн алуу же жеткирүү, төлөм ыкмасы →
  буйрутма даяр текст менен дүкөндүн **WhatsApp**'ына жөнөтүлөт
- **Оңдоо** — кызматтар жана баалар тизмеси, онлайн жазылуу (WhatsApp же чалуу)
- **Байланыш** — телефон, WhatsApp, Instagram, карта, иш убактысы
- **Менин буйрутмаларым** — буйрутмалардын тарыхы

## Админ колдонмо

Ошол эле коддон дүкөн ээси үчүн өзүнчө **«Jorgo Админ»** колдонмосу чыгат:

- Товар кошуу, өзгөртүү, өчүрүү
- Галереядан **сүрөт жүктөө**
- **Баа** жана **акция** (эски баа → жаңы баа, арзандатуунун % автоматтык эсептелет)
- «Сатыкта бар / жок» бир басуу менен
- Башкы беттеги **акция баннерлерин** кошуу/өчүрүү
- Email + сырсөз менен кирүү

```bash
npm run start:admin     # админ колдонмону иштетүү
```

Кардар колдонмосунда да `/admin` дареги бар («Байланыш» барагынын ылдыйында), бирок ага сырсөзсүз кирүүгө болбойт.

### Серверди туташтыруу (Supabase, акысыз)

Сервер туташмайынча колдонмо **демо режимде** иштейт: админдин өзгөртүүлөрү ошол түзмөктө гана сакталат (PIN: `1234`).
Өзгөртүүлөр бардык кардарларга жетиши үчүн:

1. https://supabase.com сайтында катталып, жаңы долбоор (project) түзүңүз.
2. **SQL Editor** → `supabase/schema.sql` файлын толугу менен көчүрүп, **Run** басыңыз.
3. **Authentication → Users → Add user** — өзүңүзгө email жана сырсөз менен админ аккаунт түзүңүз.
4. **Authentication → Sign In / Providers → Email** — «Allow new users to sign up» дегенди **өчүрүңүз**
   (болбосо бөтөн адамдар катталып, товарларды өзгөртө алат).
5. **Project Settings → API** бөлүмүнөн URL жана `anon` ачкычты алып, `.env.example` файлын `.env` деп көчүрүп, ичине жазыңыз.
6. Колдонмону кайра иштетиңиз, админ колдонмого кирип, «Мисал товарларды жүктөө» баскычын басыңыз (же өз товарларыңызды кошуңуз).

## Өзүңүзгө ылайыкташтыруу

| Эмне | Файл |
|---|---|
| Дүкөндүн аты, телефон, WhatsApp, дарек, жеткирүү баасы | `src/config/shop.ts` |
| Товарлар, баалар, сүрөттөр, акциялар | **Админ колдонмо** аркылуу |
| Баштапкы (мисал) товарлар жана категориялар | `src/data/products.ts` |
| Сервердин жөндөөлөрү | `.env` (`.env.example` караңыз) |
| Оңдоо кызматтары жана баалары | `src/data/services.ts` |
| Түстөр | `src/config/theme.ts` |

> ⚠️ `src/config/shop.ts` ичиндеги `whatsapp` жана `phone` азыр мисал номерлер — өзүңүздүкүнө алмаштырыңыз.

## Иштетүү

```bash
npm install
npx expo start        # QR-кодду телефондогу Expo Go менен сканерлеңиз
npx expo start --web  # браузерде ачуу
npm run typecheck
```

## Play Market / App Store'го чыгаруу

```bash
npx eas-cli@latest build --platform android   # .aab / .apk
npx eas-cli@latest build --platform ios
APP_VARIANT=admin npx eas-cli@latest build --platform android   # админ колдонмо
```

## Кийинки кадамдар (сунуштар)

- Онлайн төлөм системасын туташтыруу
- Push-билдирмелер (буйрутманын статусу)
