# Jorgo — электровелосипед дүкөнү (мобилдик колдонмо)

Электровелосипеддерди, запчасттарды сатуу жана оңдоо кызматы үчүн онлайн-дүкөн.
React Native + Expo (SDK 58) + Expo Router менен жазылган — Android, iOS жана веб үчүн бир код.

## Мүмкүнчүлүктөр

- **Башкы бет** — категориялар, популярдуу товарлар, оңдоо кызматына баннер
- **Каталог** — издөө, категория боюнча чыпкалоо, баа боюнча иреттөө
- **Товар барагы** — сүрөттөмө, мүнөздөмөлөр, арзандатуу, сатыкта бар/жок, WhatsApp аркылуу суроо
- **Себет** — санын өзгөртүү, өчүрүү, акысыз жеткирүүгө чейинки сумма (телефондо сакталат)
- **Буйрутма берүү** — аты, телефон, дүкөндөн алуу же жеткирүү, төлөм ыкмасы →
  буйрутма даяр текст менен дүкөндүн **WhatsApp**'ына жөнөтүлөт
- **Оңдоо** — кызматтар жана баалар тизмеси, онлайн жазылуу (WhatsApp же чалуу)
- **Байланыш** — телефон, WhatsApp, Instagram, карта, иш убактысы
- **Менин буйрутмаларым** — буйрутмалардын тарыхы

## Өзүңүзгө ылайыкташтыруу

| Эмне | Файл |
|---|---|
| Дүкөндүн аты, телефон, WhatsApp, дарек, жеткирүү баасы | `src/config/shop.ts` |
| Товарлар жана категориялар | `src/data/products.ts` |
| Оңдоо кызматтары жана баалары | `src/data/services.ts` |
| Түстөр | `src/config/theme.ts` |

> ⚠️ `src/config/shop.ts` ичиндеги `whatsapp` жана `phone` азыр мисал номерлер — өзүңүздүкүнө алмаштырыңыз.

## Иштетүү

```bash
npm install
npx expo start        # QR-кодду телефондогу Expo Go менен сканерлеңиз
npx expo start --web  # браузерде ачуу
npm run typecheck
```

## Play Market / App Store'го чыгаруу

```bash
npx eas-cli@latest build --platform android   # .aab / .apk
npx eas-cli@latest build --platform ios
```

## Кийинки кадамдар (сунуштар)

- Товарлардын чыныгы сүрөттөрүн кошуу (азыр иконкалар колдонулат)
- Админ-панель / сервер (товарларды колдонмону жаңыртпай өзгөртүү үчүн)
- Онлайн төлөм системасын туташтыруу
- Push-билдирмелер (буйрутманын статусу)
